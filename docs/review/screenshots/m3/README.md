# APP-004 M3｜候補5点レビュー画像

QC-v4元ZIPからSHA-256一致で復元し、元画像に遡って余白を再調整した透明RGBAアイコンとネコの試作。
文言と操作を維持したDraft実装。正式採用ではありません。
390px幅Chromiumの架空データで撮影。iPhone Safari実機ではありません。
