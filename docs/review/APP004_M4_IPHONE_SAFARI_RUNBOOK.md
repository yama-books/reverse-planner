## 画面と操作の確認観点

1. HOME: 320/390/428pxで横スクロールがなく、時計/カレンダーの下端や縁が切れず、カード全域を押せる。ネコの地面画素が途切れず背景に白枠が浮かない。
2. SETUP: 「追加」「くわしく設定」のアイコン下端が切れず、詳細を開閉できる。タスクを1件追加/編集/削除してボタンのタッチ領域が狭すぎないか見る。
3. PLAN: 余裕のある期限では旗ネコを表示し、期限不足警告では旗ネコが出ない。タイムラインと「この計画ではじめる」のラベル/再生アイコンを確認。
4. RUN: タイマーネコが1匹。スタート/一時停止の操作とタイマーカウントの表示を検証。
5. DONE: RUN内の完了状態。タイマーネコから祝福ネコ1匹に切り替わる。保存復帰時も完了表示が残る。
6. 共通: 画面拡大・文字拡大、回転、Safari下部バー表示/非表示、ソフトウェアキーボード、VoiceOver読み上げ、フォーカス/キーボード操作。暗背景・ピンク/緑ボタンの縁取りや色差を検品する。
